# Forest Quest

Plataformas en pixel art para el navegador, hecho con Phaser 3: tres niveles y un jefe final.

## Jugar

```bash
python3 -m http.server 8000
```

Abre <http://localhost:8000>.

Flechas o A/D para caminar, ↑ o W para saltar, Espacio o J para la espada, X o K para la magia, P para pausar y M para el sonido. En el móvil hay controles táctiles.
